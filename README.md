# LUMINA • AI Music Video Studio

**Revolutionary real-time AI music video production from your phone or iPad.**

Be the Quentin Tarantino of music videos. Live camera feed + instant look changes, location swaps, cinematic styles, lighting, and production tools — all without a crew, sets, or traditional production.

## Features
- Live webcam performance with face tracking overlay
- Instant location / scene changes
- Look & style transformations while staying in live action
- Cinematic presets (including Tarantino-style high contrast, grain, dramatic lighting)
- Timeline, beat sync simulation, and pro export tools
- Fully interactive from mobile / iPad

## Live Demo
Deployed on Vercel.

## Run Locally
Open `index.html` in any modern browser. Allow camera access for the full experience.

Built with pure HTML/CSS/JS for maximum portability and zero dependencies.
